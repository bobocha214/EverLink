# 工业物联网调试工具 — 功能模块拆解设计

> 面向对象：现场工控调试工程师
> 范围：多协议调试、网络诊断、独立计算工具、可视化、局域网快传增强
> 约束：**仅做功能模块拆解与实现方案设计，不涉及 APK 打包/构建实现**

---

## 0. 总体架构建议（贯穿各模块）

- **分层**：协议层（Modbus/MQTT/OPC UA/HTTP·TCP·UDP） → 会话/连接管理层 → 采集与解析层 → 可视化/存储层 → 工具与配置层。
- **能力复用**：
  - 「网络信息面板」「局域网网段扫描」与现有 EverLink 的 `NetworkInfoService`（统一取 IP/子网/网关/DNS/WiFi 名称/信号）和 UDP 多播设备发现可直接复用，避免重复实现。
  - 「局域网快传增强」基于现有快传架构（HTTP Server + UDP 多播发现 5321、剪贴板独立服务 5322），在其上扩展模板/CSV 传输、聊天室、断点续传。
- **异步与生命周期**：所有阻塞协议操作（Socket、TLS 握手、定时轮询）必须跑在独立 isolate / 后台线程，UI 只消费流式数据，避免 ANR。
- **配置驱动**：连接参数统一抽象为「连接配置模型」，所有协议模块与「配置模板管理」共用，降低耦合。

## 一、Modbus 增强功能

### 1.1 核心逻辑
- **链路层**：优先实现 Modbus RTU over TCP（端口 502），报文 = MBAP 头(7B) + 功能码 + 数据；后续可扩展串口 RTU（需平台串口权限，建议二期）。
- **功能码封装**：05(写单线圈)/06(写单寄存器)/15(写多线圈)/16(写多寄存器)，请求体按规范组帧，CRC 校验（RTU 模式下）由底层负责。
- **数据解析引擎**：寄存器原始字（16bit）按目标类型重组：
  - INT16/UINT16 直接映射；INT32/UINT32/FLOAT32 按「寄存器顺序 + 字节序」组合（4 字节 = 2 寄存器）；
  - BCD 按每 4bit 译十进制；高低字节互换（word/byte swap）作为独立开关，覆盖工控高频高低位颠倒场景。
- **批量轮询**：以「点位表」为输入，按地址区间拆分为连续读请求，定时（ms 级）循环下发 0x03/0x04。

### 1.2 关键能力
- 单/多寄存器读写、强制线圈（05/15）。
- 数据类型可视化解析：同一寄存器可切换 INT16/FLOAT32 等查看，高低字节互换一键切换。
- 定时采集 + 实时曲线：采集数据写入环形缓冲，驱动趋势图（见模块九）。
- 原始十六进制报文收发查看（请求/响应分栏 hex dump）。
- 收发日志导出（文本/CSV，含时间戳、方向、报文、解析值）。
- 局域网网段自动扫描 Modbus 从站（TCP 502 端口探测，复用 UDP/TCP 探测能力）。

### 1.3 边界与注意事项
- **字节序是头号坑**：不同 PLC 厂商寄存器排列差异极大（AB CD / CD AB / BA DC…），必须提供「字交换 / 字节交换」独立组合选项，并在模板中固化。
- **轮询频率上限**：高频轮询（<200ms）需评估从站负载，避免压垮低端设备；建议 UI 限速与合并连续区间。
- **RTU over TCP vs 串口 RTU**：本期建议只做 TCP，串口需原生权限与硬件，列入二期。
- **大数据量**：单次读寄存器数量受 PDU 长度限制（≤125 寄存器/帧），多寄存器需自动分帧。

## 二、MQTT 增强功能

### 2.1 核心逻辑
- **连接管理**：封装 MQTT 客户端（推荐 mqtt_client 类库），支持 3.1.1 / 5.0；TLS/SSL 通过安全套接字 + CA/客户端证书加载。
- **认证**：用户名密码、X.509 证书双通道；MQTT5 可携带连接属性（如会话过期）。
- **订阅模型**：主题树 = 多订阅条目集合，每条绑定 QoS；`#`(多层) / `+`(单层) 通配符按协议规范匹配。
- **报文处理**：入站消息按主题路由到对应视图；JSON 报文进入格式化/高亮管线。

### 2.2 关键能力
- MQTT3.1.1 / MQTT5、TLS/SSL、用户名密码/证书认证。
- QoS 0/1/2 发布与订阅。
- 多主题订阅 + 通配符 `#` `+`。
- JSON 报文格式化、语法高亮、简易 JSON 编辑器（字段增删改）。
- 消息历史记录（带主题/时间/QoS/ payload），发布消息模板保存（常用指令一键重发）。

### 2.3 边界与注意事项
- **MQTT5 与 3.1.1 差异**：共享订阅、用户属性、原因码等仅 5.0 支持，需做能力降级提示。
- **证书安全**：客户端证书/私钥存本地加密区，禁止明文落盘。
- **通配符订阅风暴**：`#` 在海量主题下会淹没 UI，需限流/折叠与主题过滤。
- **QoS2 重传**：网络抖动下注意重复投递与本地去重。

## 三、OPC UA 增强功能

### 3.1 核心逻辑
- **会话建立**：Endpoint 发现 → 安全策略协商（None / Basic256Sha256 / Basic128Rsa15 等）→ 认证（匿名/用户名/证书）。
- **地址空间浏览**：递归读取节点树（Object/Variable/Method），按 `browseName` 树形展开，懒加载子节点。
- **订阅监控**：对变量节点建立 Subscription + MonitoredItem，服务端按采样率推送数值（Publish/Notify）。
- **读写**：变量节点 DataValue 读写；原始请求/响应报文（UA 二进制或 XML）可抓看。

### 3.2 关键能力
- 安全策略切换（None / Basic256Sha256 等）+ 用户名/证书登录。
- 节点浏览器（树形地址空间）。
- 节点定时订阅监控，实时数值展示。
- 变量读写，原始通信报文查看。

### 3.3 边界与注意事项
- **证书信任链**：自签证书需导入信任列表，否则握手失败；提供证书导入/信任管理 UI。
- **性能**：深层节点树必须懒加载 + 缓存，避免一次性 Browse 卡死。
- **订阅保活**：断线重连需重建 Subscription（服务端不保留），需实现自动重订阅。
- **命名空间**：节点 ID 含 namespaceIndex，读写时必须携带正确 ns，模板配置需固化。

## 四、通用网络调试客户端

### 4.1 HTTP / TCP Socket 调试
- **核心逻辑**：TCP 客户端 = 建立 Socket → 收发字节流 → 按分隔符/长度解析；HTTP 层在 TCP 之上组装请求行+头+体，解析状态行/响应头/响应体。
- **关键能力**：自定义 TCP 客户端；HTTP/HTTPS 测试；GET/POST（可扩 PUT/DELETE）；自定义请求头；对接设备 HTTP 接口；HTTPS 可忽略证书（调试用开关）。
- **边界**：HTTPS 证书忽略仅限调试模式并显著告警；大响应体流式读取防 OOM。

### 4.2 端口扫描器
- **核心逻辑**：对目标 IP/网段并发 TCP `connect`（带超时），开放端口即记录；预置工控端口 502/1883/4840/80/443 + 自定义列表。
- **关键能力**：网段扫描、常用端口预置、自定义端口列表、结果列表（IP:端口/服务猜测）。
- **边界**：并发度需可控（避免被网关/IDS 限流或误判攻击）；移动网络下扫描局域网更稳妥，公网扫描需提示合规风险。

### 4.3 Traceroute 路由追踪
- **核心逻辑**：发送 TTL 递增的 UDP/ICMP 探测包，记录每跳 IP 与 RTT；移动端可用 `ping`/raw socket 能力受限时，降级为逐跳 TCP/ICMP 探测或服务端代理。
- **关键能力**：逐跳延迟、超时标记、* 不可达显示；用于跨网段延迟/断点排查。
- **边界**：部分网络禁 ICMP 会全 `*`，需说明并支持 TCP 探测兜底；结果仅作参考。

### 4.4 网络信息面板
- **核心逻辑**：聚合本机网络状态——IP 列表（按接口/WiFi/蜂窝）、子网掩码、网关、DNS、WiFi 名称、信号强度。
- **关键能力**：连接类型横幅（WiFi/移动数据/以太网着色区分）、所有 IP 带类型徽章、可复制、网关/子网/DNS/BSSID/信号展示。
- **边界**：**可直接复用现有 EverLink `NetworkInfoService`**（已解决 WiFi/流量区分、子网掩码由 LinkProperties 推导、SSID 现代 API 读取），无需重造。Android 10–12 拿 SSID 需定位授权，已做一次性申请。

### 4.5 TCP/UDP 简易收发日志视图
- **核心逻辑**：协议层把每次收发事件（方向、时间、长度、前 N 字节摘要/全量 hex）投递到日志流；移动端不做底层抓包。
- **关键能力**：收发日志时间线、hex 预览、按连接/协议过滤、导出。
- **边界**：**以「协议收发日志」替代抓包**，明确告知用户这不是 pcap 级抓包；多连接时按会话分组。

## 五、数据记录仪

### 5.1 核心逻辑
- 采集源 = Modbus/MQTT/OPC UA 三者的实时数据点；记录器订阅这些数据点，按固定周期（如 1s/5s/1min 可配）落盘。
- 存储 = 本地 CSV（表头：时间戳、来源、点位、值、单位），环形或按文件大小/时间分卷。

### 5.2 关键能力
- 定时保存为本地 CSV；支持导出与文件分享（可走模块八快传分享）。
- 用于现场长时间测试、记录设备波动数据（如温度漂移、压力波动）。

### 5.3 边界与注意事项
- **落盘频率与性能**：高频写入用追加写 + 批量缓冲，避免每点一次 IO；建议 ≥1s 粒度。
- **存储上限**：必须做容量上限/自动分卷，防止撑满手机存储。
- **数据来源解耦**：记录仪只消费「标准化数据点事件」，不直接耦合各协议实现。

## 六、独立十六进制调试工具页（离线，无需连接设备）

### 6.1 核心逻辑
- 纯本地计算：字符串 ↔ Hex（ASCII/UTF-8 编码可选）、大小端转换（16/32/64bit 字节序翻转）、浮点解析（IEEE754 由寄存器值算 FLOAT32）。
- CRC16-Modbus：按标准算法（多项式 0x8005，初始 0xFFFF，反射）实现，输入 hex/字节流，输出校验值。

### 6.2 关键能力
- 字符串 ↔ Hex 互转；大小端转换；浮点数寄存器解析计算。
- CRC16-Modbus 校验计算器（Modbus 调试高频工具，支持输入报文即时算校验）。

### 6.3 边界与注意事项
- 完全离线、零权限，可作为「工具箱」常驻入口。
- CRC 参数（多项式/初始值/反射/异或输出）建议提供常用预设（Modbus/CCITT 等）并可手动覆盖。

## 七、设备连接配置模板管理

### 7.1 核心逻辑
- **连接配置模型**：{ 协议类型, IP, 端口, 点位表, 字节序, 认证信息, 采集周期 } 统一结构。
- **模板仓库**：本地存储（SQLite/文件），支持分组、命名、一键加载。
- **导入导出**：序列化为 JSON，支持文件导入导出 + 局域网分享（走快传）。

### 7.2 关键能力
- 整套连接参数保存为模板；一键加载、分组管理。
- JSON 格式导入导出；局域网分享配置。

### 7.3 推荐增值功能（并入本模块）
- **二维码扫码导入**：将完整连接参数编码为二维码（或短 JSON URI），扫码直接导入，免手动录 IP。注意二维码容量限制，超长配置用「二维码存分享链接 + 局域网拉取」或压缩。
- **NTP 时间同步客户端**：连接 NTP 服务器获取标准时间，用于现场设备校时、工控时序调试；展示服务器时间/本地偏差，可触发设备校时指令（需设备支持）。

### 7.4 边界与注意事项
- **敏感信息**：认证密码/证书在模板 JSON 中需加密或提示「含密钥请勿明文分享」。
- **版本兼容**：模板 JSON 需带 schema 版本号，旧版模板加载做字段兼容/迁移。

## 八、现有局域网快传扩展优化

> 基于现有 EverLink 快传架构（HTTP Server + UDP 多播发现，文件传输已具备）做增强，不重写底层。

### 8.1 传输配置模板 / CSV 采集日志
- **核心逻辑**：传输对象从「普通文件」抽象为「可分享载荷」，扩展 MIME/类型标记，使配置模板(JSON)、CSV 日志可作为一类对象收发。
- **关键能力**：快传不仅能发文件，还能直接发/收配置模板与采集日志，接收端可「一键应用模板/导入 CSV」。
- **边界**：模板含密钥时接收端提示风险；CSV 大文件走 8.3 续传。

### 8.2 局域网简易文本聊天室
- **核心逻辑**：在现有 UDP/HTTP 通道上增加「聊天消息」类型（轻量广播/点对点），复用设备发现得到的在线成员列表。
- **关键能力**：调试人员互发 IP、点位地址等短信息；消息带发送者/时间；可配合复制。
- **边界**：仅局域网内、不与文件传输抢占带宽；消息不落盘或仅临时缓存；明确告知用户这不是加密 IM。

### 8.3 大文件断点续传 + 进度曲线
- **核心逻辑**：文件分块传输，记录已确认块偏移；断线后从偏移续传；进度事件驱动进度条 + 速率曲线。
- **关键能力**：断点续传、传输进度展示、传输速率/进度曲线（趋势图组件复用模块九）。
- **边界**：块大小与设备存储对齐；续传需双方支持偏移协议（收发端版本协商）；进度曲线仅展示，不做持久记录。

## 九、可视化功能

### 9.1 实时数据趋势曲线
- **核心逻辑**：任意采集点位 → 时间序列缓冲 → 折线渲染；支持缩放、滑动回看、暂停、截图保存（导出图片）。
- **关键能力**：多点位叠加、时间轴缩放、回看历史、暂停冻结、截图导出。
- **边界**：历史数据来自模块五 CSV 或内存环形缓冲；移动端内存有限，回看窗口需设上限或走文件流式读取。

### 9.2 简易仪表盘组件
- **核心逻辑**：模拟量（温度/压力等）映射到仪表盘刻度（min/max/单位），实时数值驱动指针/进度弧。
- **关键能力**：数值仪表盘可视化（温度、压力等），阈值变色告警。
- **边界**：仪表盘数量与刷新率可控，避免过多动画掉帧；阈值在配置模板中固化。

## 十、轻量实用小工具（低成本）

- **工控单位换算**：摄氏度/华氏度、长度、压力（bar/psi/kPa/MPa）、流量等；纯公式，离线。
- **时间戳转换**：Unix 时间戳 ↔ 北京时间（含时区处理，注意设备本地时区与 UTC 区分）。
- **IP 计算器**：输入 IP + 子网掩码，计算网段、广播地址、可用主机范围、CIDR；可复用模块四.4 的网络信息。

**边界**：全部离线、零权限、低开发成本，适合作为「工具箱」常驻，提升日活与粘性。

## 附录：模块依赖与落地建议（咨询视角）

1. **基座优先**：先做「网络信息面板(四.4) + 端口扫描(四.2) + 十六进制工具(六) + 小工具(十)」——零协议依赖、快速出可用版本、验证基础 UI/存储能力。
2. **协议三件套**：Modbus(一) → MQTT(二) → OPC UA(三) 按现场需求优先级排期；三者共用「连接配置模型(七)」与「数据点事件总线(供五/九消费)」。
3. **数据闭环**：配置(七) → 采集(一/二/三) → 记录(五) → 可视化(九) 形成核心闭环。
4. **快传增强(八)**：在已有快传之上增量扩展，聊天室/续传为锦上添花，可后置。
5. **复用提示**：网络信息、UDP 设备发现、CRC 计算等已有实现/成熟算法，避免重复造轮子。
